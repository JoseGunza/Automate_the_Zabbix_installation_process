# Automate_the_Zabbix_installation_process
The idea is to simplify the Zabbix configuration process for users new to Linux systems.

# Zabbix version:
   - Zabbix Server: 7.0.x

# Sistems:
   - Ubuntu 18.04 / 20.04 / 22.04 / 24.04 / 26.04
   - AlmaLinux 8 / 9 / 10
   - CentOS 8 / 9 / 10

# Steps to use:
1- wget https://raw.githubusercontent.com/JoseGunza/Automate_the_Zabbix_installation_process/refs/heads/main/install-zabbix-agent2.sh
2- chmod +x install-zabbix-agent2.sh
3- sudo ./install-zabbix-agent2.sh
